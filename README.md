# AI Collaborative Code Editor

AI-Enhanced Real-Time Collaborative Code Editor with XAI

A real-time collaborative coding platform that allows multiple users to write, edit, and review code together. The project combines live collaboration, AI-powered code analysis, code execution, and analytics to create a productive coding environment for teams and learners.

## Features

-> Real-time collaborative code editing
-> Room-based collaboration
-> AI-powered code review using OpenRouter
-> Multi-language code execution
-> User and room analytics dashboard
-> Session tracking and activity logging
-> MongoDB-based data storage

## Tech Stack

**Frontend**

* HTML
* CSS
* JavaScript
* Monaco Editor

**Backend**

* Node.js
* Express.js
* Socket.IO

**Database**

* MongoDB Atlas

**AI Integration**

* OpenRouter API

## Project Highlights

1. Enables multiple users to collaborate on the same code in real time.
2. Provides AI-generated suggestions for improving code quality.
3. Tracks user contributions and collaboration metrics.
4. Supports code execution and output visualization.
